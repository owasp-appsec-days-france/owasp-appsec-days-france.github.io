# france-owasp-day
OWASP AppSec Days France conference site &amp; presentation archive

Based on the [OWASP AppSec Days German conference site](https://god.owasp.de)

## How to use?

```
git clone git@github.com:owasp-appsec-days-france/owasp-appsec-days-france.github.io.git
cd owasp-appsec-days-france.github.io/
python3 -m http.server
firefox http://localhost:8000/2026/index.html
```
